# Galaxy Sports Arena

## What Is This?

Galaxy Sports Arena is a browser-based multi-sport gaming portal built
with a stunning space galaxy theme. It features 6 different sports games
that you can play directly in your browser using keyboard and mouse controls.


## Games Included
1. Beyblade Battle — Spin your beyblade and battle an AI opponent in a galaxy arena
2. Space Cricket — Face an AI bowler and time your shots to score runs
3. Galaxy Volleyball — Control your player and spike against the AI
4. Table Tennis — Rally against an AI opponent using mouse or arrow keys
5. Kabaddi Raid — Raid the opponent side, tag defenders and return safely
6. Kho-Kho Chase — Run and dodge AI chasers as long as possible

## How To Play

Just open index.html in any browser — no installation needed!

Controls:
- Arrow Keys to move your player
- Space bar for action (jump, attack, tag)
- Mouse for Table Tennis paddle control

## Tech Used

- HTML5 Canvas for game rendering
- JavaScript for game logic and AI
- CSS3 for galaxy animations and space theme
- AI opponents that adapt difficulty as you play

## AI Features

Each game has an AI opponent built using different strategies:
- Beyblade: AI chases and attacks player beyblade
- Cricket: AI bowler increases difficulty after boundaries
- Volleyball: AI predicts ball position and jumps accordingly
- Table Tennis: AI speed increases as rally continues
- Kabaddi: AI defenders converge on raider in enemy zone
- Kho-Kho: AI chasers speed up every 5 seconds

## Developer Notes

I built this project because I wanted to create something that combines
the games I grew up watching and playing in India with modern web technology
and AI. Kabaddi and Kho-Kho are games that almost no one builds digitally
and I wanted to change that.
